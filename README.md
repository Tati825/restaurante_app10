# restaurante_app10
Nombre: Erika Tatiana España Valdez
Se agregaron las bibliotecas Tkinter/ttk permitiendo la gestión tanto de usuarios como de productos por medio de una interfaz gráfica. Se puede iniciar sesión con los usuarios registrados en el json correspondiente. Se cumple con los propósitos mínimos solicitados como son la organización de la interfaz por medio de contenedores, la utilización de botones, consulta de usuarios desde la interfaz, etc.
